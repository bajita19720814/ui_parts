UI Components

Webでよく使われる基本的なUIコンポーネントをまとめています。

Tabs タブメニュー

複数のコンテンツを切り替えるシンプルなタブUIです。

Accordion アコーディオン

質問や情報を折りたたんで整理できるアコーディオンUIです。

Hamburger Menu ハンバーガーメニュー

スマホ向けのナビゲーションを開閉できるメニューUIです。

Modal Window モーダルウィンドウ

ボタン操作で中央に表示されるポップアップUIです。

Slide Carousel スライドカルーセル

ボタンで画像を横方向にスライドして切り替えるカルーセルUIです。

Slide Carousel スライドカルーセル

スワイプで画像を横方向にスライドして切り替えるカルーセルUIです。

Crossfade Slider クロスフェードスライダー

画像がふんわり重なりながら切り替わるクロスフェード式のスライダーです。

Grid Layout グリッドレイアウト

コンテナ幅に応じて列数が変化するレスポンシブなグリッドレイアウトです。

Interactive Features

操作や動きによって変化するインタラクティブなUIパーツをまとめています。

Slideshow スライドショー

画像を左右に切り替える軽量スライドショー。サムネイル選択にも対応しています。

Loading Spinner ローディングアイコン

読み込み中であることを示すシンプルなスピナーアニメーションです。

Dragg & Drop ドラッグアンドドロップ

要素をドラッグして自由に配置できるインタラクションのデモです。

Scroll Reveal スクロールリビール

スクロールに合わせてコンテンツがふんわり表示されるアニメーションです。
