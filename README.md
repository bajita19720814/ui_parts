# My UI Parts – Reusable Web Components

Web サイト制作でよく使う UI コンポーネントを
シンプルな HTML / CSS / JavaScript でまとめたコレクションです。

## Components List
- Tabs
- Accordion
- Hamburger Menu
- Modal Window
- Slide Carousel
- Crossfade Slider
- Grid Layout
- Slideshow
- Loading Spinner
- Dragg & Drop
- Scroll Reveal
- Calendar
- Stopwatch
